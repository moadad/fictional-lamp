# Jood Orders Pro — تطوير المخزن والعملاء

## ما تم تطويره
- شاشة **تشغيل المخزن** بدل عرض الموديلات التقليدي: المطلوب، المخزون، المحجوز، المتاح، العجز، وعدد العملاء.
- شاشة مستقلة **ملف العميل** بزر مستقل عن زر فتح الطلبية.
- البحث الشامل من مربع واحد: اسم العميل، رقم الفاتورة، رقم الموديل.
- فهرس بحث محلي سريع مع الرجوع للخادم فقط عند عدم وجود نتيجة محلية.
- حجز المخزون مع حجز تلقائي حسب ترتيب العملاء، ودعم خادم مركزي عند تفعيله.
- مستندات طباعة A4 للطلبية، ملف العميل، وأمر تجهيز المخزن، مع أرقام الفواتير والتسلسل والتوقيعات.
- فصل الكود إلى `index.html` و`styles.css` و`api.js` و`app.js`.
- Cache قصير المدة وdeduplication للطلبات لتقليل ضغط الاتصال.
- تحميل تفاصيل عملاء الموديل بعد فتحه فقط وبعدد متزامن محدود بدل تحميل كل التفاصيل مقدمًا.
- رفع مستوى الجلسة والأمان ودعم Token/POST عند توفرهما من الخادم.

## ملاحظة الحجز المركزي
الحجز الحقيقي المتزامن بين كل الأجهزة يحتاج أن يدعم الخادم `reserveStock` و`releaseReservation` بشكل ذري (Atomic). حتى ذلك الحين يحفظ وضع التوافق الحجوزات على الجهاز الحالي.


## إصلاح V4.1
- إصلاح تسجيل الدخول مع خادم Google Apps Script الحالي: استخدام JSONP/GET أولًا كما في النسخة الأصلية.
- إزالة المسافات العرضية من بداية/نهاية كلمة المرور.
- رفع إصدار Service Worker لمنع بقاء ملف تسجيل الدخول القديم في الكاش.


## قاعدة التسليم V4.2
- أي موديل تم تسجيل كمية تسليم له أكبر من صفر يعتبر **تم التسليم**، سواء كانت الكمية أقل من المطلوب أو مساوية له أو أكثر منه.
- تظل كمية **المطلوب** و**المسلّم فعليًا** ظاهرة للمراجعة.
- المتبقي التشغيلي لهذا الموديل يصبح صفرًا، ولا يعاد للحجز أو التجهيز مرة أخرى.


## تحديث V4.3 - طباعة أوردر العميل
- إضافة زر مستقل **طباعة أوردر العميل** داخل شاشة الطلبية.
- الطباعة الجديدة تستخدم كامل موديلات العميل حتى عند الدخول من تبويب الجاهز.
- لا تعرض: المخزون، المحجوز، المتاح، المتبقي.
- تعرض: التسلسل، رقم الفاتورة، الموديل، المطلوب، المسلم، الحالة، والإجماليات والتوقيعات.
- طباعة المخزن القديمة بقيت مستقلة دون تغيير.


## تحديث V4.4
- طباعة أوردر العميل: م، الموديل، المطلوب، المسلّم، الحالة فقط.
- الحالة في الطباعة: متاح في المخزن / غير متاح في المخزن حسب المخزون الحالي.
- البحث العام محصور باسم العميل أو رقم الفاتورة فقط.
